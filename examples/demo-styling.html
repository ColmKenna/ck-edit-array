🎨 Styling with ::part()

External styling of Shadow DOM elements using CSS ::part() selectors

Main demo | Advanced demo | Button slots

📋 Available CSS Parts

The component exposes these part attributes on its Shadow DOM elements:

Part Element Description
containerRoot wrapperThe outer container for the whole component
items-containerItems listWraps all item rows
action-barAction barBottom bar with the "Add" button
itemItem wrapperEach individual item row
display-containerDisplay cloneRead-only content area
edit-containerEdit wrapperEdit form container
button-barButton groupEdit / Delete / Cancel buttons container
add-buttonAdd buttonThe "Add New Item" button
input<input>All cloned inputs in the edit template
select<select>All cloned selects in the edit template
textarea<textarea>All cloned textareas in the edit template
label<label>All cloned labels in the edit template

🎨 Interactive Style Presets

Click a preset to instantly restyle the component. All styling is applied purely via ::part() selectors — no JavaScript is involved in the style changes.

💻 Code Examples

Basic Input Styling

/* Style all inputs, selects, and textareas */ ck-edit-array::part(input), ck-edit-array::part(select), ck-edit-array::part(textarea) { width: 100%; padding: 0.5rem 0.75rem; border: 1px solid #d1d5db; border-radius: 6px; font-size: 0.95rem; font-family: inherit; } ck-edit-array::part(input):focus { outline: none; border-color: #3b82f6; box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.15); }

Edit Container Background

ck-edit-array::part(edit-container) { background: #f9fafb; padding: 1rem; border-radius: 8px; border: 1px solid #e5e7eb; }

Label Styling

ck-edit-array::part(label) { display: block; font-weight: 600; margin-bottom: 0.25rem; color: #374151; }

Scoped Styling (Target Specific Instances)

/* Only style inputs in a specific component instance */ #my-component::part(input) { border-color: #10b981; } /* Style inputs inside a wrapper class */ .dark-form ck-edit-array::part(input) { background: #1f2937; color: #f9fafb; border-color: #4b5563; }
